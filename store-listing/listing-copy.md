# Ceiling Microsoft Store listing — English (United States)

Prepared for the first Store submission using installer version 1.4.0.

## Product name

Ceiling: AI Usage Monitor

## Description

Ceiling is a focused, local-first Windows companion for the AI subscriptions you use. It keeps remaining capacity, reset times, and stale or error states visible from a compact tray flyout, full dashboard, or optional strip above the Windows taskbar.

Track OpenAI Codex, Claude, Cursor, Gemini, GitHub Copilot, and OpenCode Go in one place. See which limit is closest, when each window resets, and how usage changes over time. Optional Windows notifications warn you as limits approach and tell you when capacity resets or is restored.

Charts use local session history to show token activity and estimated API-equivalent value for supported providers. Estimates are clearly labeled and are not subscription bills.

Ceiling does not require a Ceiling account. Credentials and usage data stay on your PC. The app reads local sessions or contacts the provider endpoint you enable; it does not send your credentials or usage data to Ceiling-operated servers.

Free, open source, and designed for Windows 10 and 11.
